## 边界与下一轮
这是 2.5D 实时绘画，不是完整人物骨骼、真实布料或流体仿真。山水中的所有树枝、亭台并未逐个拆解运动；旧入口和阅读器的历史转场/生长问题不是本轮全量重写范围。

下一轮优先顺序：
1. 按当前构图拆出人物衣摆、发梢、蓑衣、剑穗独立层；用明确固定点与骨骼权重取代局部近似形变。
2. 将首屏主题与进入阅读器的相机位置/主体锚点对齐，做连续进入同一山水的共享对象转场。
3. 水面反射与船桨动作联动、叶片对遮挡物响应，减少装饰性随机运动。
4. 做真实 PC GPU 帧时间测量，再决定合并 WebGL 上下文、延迟加载场景与拆分主包；不以“PC 优先”作为无限制堆渲染的理由。
