# 水墨武侠

当前版本：V30。仓库名称：ui-design。保留原界面的“枫落见锋”题字与内容。

PC 优先的水墨武侠交互界面，使用 React、Vite、Three.js、Canvas 与 GSAP。保留首页、剑录、江湖志三条独立路由，以及搜索、阅读、收藏和动态开关。

当前江湖志精选首屏由 JournalWorld 负责：山行、渡水、藏锋三套分层场景，共享风势交互、主题切换和静画回退。具体实现与边界见 [验收记录](docs/v30/acceptance.md)。这是实时 2.5D 绘画界面，不是完整人物骨骼或物理流体模拟。

## 开发与检查

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
npm run build
node --test tests/*.test.mjs
```

路由：`#/`、`#/jianlu`、`#/jianghu`。构建输出位于 dist/，包含 Sites 所需客户端、服务端和 hosting 配置。
